## Overview

Packages are curated collections of triggers for common tasks. Install them with one click and start using them immediately.

## Available Packages

| Package | Triggers | Description |
|---|---|---|
| Date & Time | 12 | Date/time formatters in every format |
| Code Snippets | 24 | Common code patterns for developers |
| Email Templates | 8 | Professional email starters and signatures |
| Typography | 30 | Unicode symbols, arrows, math notation |
| Lorem Ipsum | 5 | Placeholder text generators |
| Common Replies | 15 | Quick replies for chat and email |

## Installing a Package

1. Browse packages in the [Package Browser](/packages)
2. Click **Install** on any package
3. The triggers are added to your Trigger Manager
4. Start using them immediately

## Creating Your Own Package

You can create custom packages by exporting your triggers and sharing the JSON file. See [Export & Import](/docs/export-import) for details on the file format.
